# Правила работы в репозитории

- Общайся с пользователем на русском языке.
- Работай небольшими, понятными шагами.
- Перед изменениями кратко объясняй план: что собираешься изменить и зачем.
- Сохраняй существующие изменения пользователя. Не перезаписывай и не откатывай их без явного подтверждения.
- Без явного подтверждения пользователя запрещено:
  - выполнять `terraform apply` и `terraform destroy`;
  - выполнять `kubectl delete`;
  - выполнять `git push`;
  - изменять облачную инфраструктуру;
  - выполнять операции с секретами.
- Не добавляй секреты в файлы и не выводи их в сообщения, логи или вывод команд.

## Обмен заданиями и отчётами

- Используй приватный репозиторий `/home/vagrant/diplom/ai-project-context` (`myachmen/ai-project-context`, ветка `main`).
- Задания читай из `netology-diploma/exchange/task.md`, отчёты записывай в `netology-diploma/exchange/result.md` репозитория обмена.
- Перед чтением нового задания выполняй `git pull --ff-only` в репозитории обмена. При конфликте остановись.
- Выполняй только явно разрешённые операции. Не публикуй секреты.
- Commit и push отчёта разрешены только при явном указании в конкретном задании, только для `result.md` и после проверки staged diff.
- Для `terraform apply`, `terraform destroy`, `kubectl delete`, `git push` основного проекта, изменений облачной инфраструктуры и действий с секретами требуется отдельное явное подтверждение пользователя.
- Не создавай фоновые процессы.
